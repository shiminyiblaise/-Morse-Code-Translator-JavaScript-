# -Morse-Code-Translator-JavaScript-
This is a simple Morse Code Translator built using HTML, CSS, and JavaScript. It allows users to:  🔁 Convert English text to Morse code  🔁 Convert Morse code back to English text  Supports letters, numbers, and common punctuation  Designed for beginners learning JavaScript string manipulation and DOM interaction

# 📖 Morse-Code-Translator-JavaScript-<a name="about-project"></a>
     This project allows users to:
- ✅ Convert **English text to Morse code**
- ✅ Convert **Morse code back to English text**
- ✅ Handle letters, numbers, and basic punctuation
- ✅ Learn about string manipulation and event handling in JavaScript

---

*[Morse-Code-Translator-JavaScript-]* is a HTML CSS and JAVASCRIPT project but javascript project

## 🛠 Built With <a name="built-with"></a>

### Tech Stack <a name="tech-stack"></a>

- **HTML** – Page structure  
- **CSS** – Basic styling and layout  
- **JavaScript** – Core logic for encoding and decoding Morse code

---

### Key Features <a name="key-features"></a>

- Text ➡️ Morse Code conversion  
- Morse Code ➡️ Text conversion  
- Supports spaces (` `) and word separators (`/`)  
- Clear UI with real-time feedback
